capture/firefox_check.ps1 on Firefox 157.0.1 with a throwaway profile and its default sandbox, 2026-10-11. RTX VSR, RTX HDR and Windows HDR were on.
The script sizes the Firefox window to 3200x1700 on the 3840x2160 desktop and checks the size before it measures. It reads the VRAM of every Firefox process
from the Windows GPU Process Memory counters about every 2 s, stops at 6000 MB (a sample can land up to about 1 GB past that), prints the token of one
process of each type, and closes the processes of its profile. Run A used an earlier version of the script; run B used the one in this repo.
I did not record what the video looked like in these runs. I replaced the logon session number in the tokens with <n> by hand.
